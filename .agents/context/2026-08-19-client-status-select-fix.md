# Correção do select de status do cliente

## Alterações

- O trigger do select agora usa `bg-background`, evitando transparência sobre o dialog.
- O valor interno continua sendo `active` ou `inactive`.
- A apresentação do valor selecionado foi explicitamente traduzida para `Ativo` e `Inativo`.

O CRUD continua recebendo os valores em inglês, enquanto a interface permanece em português.
